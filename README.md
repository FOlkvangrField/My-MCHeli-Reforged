武器属性(导弹类)
maxDegreeOfMissile = 60
/发射后导弹最大角度。在游戏里体现为过载，数值越大，则过载越强
tickEndHoming =100
/导弹最大制导时间，如上表示导弹最大制导时间为100tick，若超过这个时间，导弹失去制导进入惯性导航。-1表示永远锁定
maxLockOnRange = 300
/导弹最大锁定距离。如上表示导弹最大制导时间为300
maxLockOnAngle = 10
/雷达和导弹最大锁定角度。可以理解为导弹导引头预热时的FOV，数值越大，导弹视场里目标越多，打击目标就越不精准（如锁A打B）
pdHDNMaxDegree = 10
/PD速度门，导弹超过这个角度后无法锁定目标。数值在20左右时，可以模拟迎头/尾追导弹，数值在80左右时，可以模拟pd导弹，会被39机动影响
pdHDNMaxDegreeLockOutCount = 10
/pd速度门雷达脱锁间隔，如上表示超过PD速度门最大角度后，导弹在10tick后失去制导
AntiFlareCount = 10
/导弹抗干扰时长，如上表示导弹若被干扰弹干扰，将会在10tick后失去制导，-1表示无抗干扰。
lockMinHeight = 25
/雷达导弹受多径杂波干扰的高度，如上表示该当导弹追踪的飞机在距地25米以下的高度时，导弹受多径杂波干扰失去制导
IsHeatSeekerMissile = false
/导弹是否为红外弹，红外弹受热诱弹干扰。true表示是false表示不是
IsRadarMissile = true
/导弹是否为雷达弹，雷达弹受箔条干扰。true表示是false表示不是
PassiveRadar = true
/导弹是否为半主动雷达弹，半主动雷达弹需要持续锁定。true表示是false表示不是

MCHR更新内容
2025.3.7之前
1，新增雷达机制
2，新增四种载具雷达
3，将mcheli原版的锁定式导弹更改为红外弹，主动雷达弹，半主动雷达弹三种类型
4，红外弹受热诱弹干扰
5，雷达弹受箔条干扰
6，半主动弹发射后需要持续锁定
8，新增导弹过载机制（通过发射后导弹最大角度实现）
9，新增导弹fov，通过导弹锁定时最大角度，角度越大，打击目标越不精确
10，新增导弹最大制导时长，制导时长过后导弹进入惯性导航
11，新增pd速度门机制。可以通过该机制模拟尾后/迎头雷达弹，和会被39机动干扰的pd雷达弹
12，新增导弹抗干扰机制，导弹被干扰后数秒才会失去制导
13，新增多径杂波机制，飞机低于一定高度能使导弹脱锁
14，新增激光制导导弹，左键发射，右键选择激光点位置，导弹会往激光点移动。激光制导导弹分为两种，一种为固定激光制导，激光点始终处于机头正对处，另一种为吊舱激光制导，可以离轴标定激光点
15，修复原版mcheli中的ASMissile类型导弹无法攻击远处目标的bug
16，优化弹药打击地面的效果
17 重构mch网络包架构
